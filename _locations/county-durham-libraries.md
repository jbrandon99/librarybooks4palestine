County Durham Libraries have a good selection of books on Palestine, predominantly non-fiction books. Few of these were published since the start of the 2023 genocide.

Reservations require a small fee. Purchase requests can be made by contacting any library but book purchase requests are generally only authorised if they have been publishded in the last three years (although this is not a strict rule).

### Book Search
To search the County Durham Library catalogue and reserve a book see the [Library Search Page](https://libraryonline.durham.gov.uk/).

### Purchase Request
To request a new book purchase, email, phone or drop into [your local library](https://www.durham.gov.uk/libraries). 

- Borrower Card Number (will be on your library card)
- Full Name
- Email Address
- Book Title
- Author
- Format (Physical Book / E-Book / Audio Book)
- Collection point
