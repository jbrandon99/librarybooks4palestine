Bradford Libraries already stock a range of books on Palestine. 

### Book Search
To search the Bradford Library catalogue and reserve a book see the [Library Search Page](https://www.bradford.gov.uk/libraries/library-services-online/library-catalogue/).

### Purchase Request
To request a new book purchase, complete the [Libries Stock Suggestion Form](https://onlineforms.bradford.gov.uk/ufs/Libraries_stock.eb?ebd=0&ebz=1_1788110536941). If you want to make a second purchase request you need to use a different browser, a private browsing window, or change devices.
